In this module, I learned about the git software and the github online platform.
I got the chance to create a github account and to create a new repository.
After creating the repository, I learned how to clone it to be able to create new files in the repo folder.
Then I learned the core git workflow of how to stage changed files and how to commit and push them to github with meaningful commit messages.
I also learned about how separate branches (not just the main/production one) can be created to work independently before merging back to the main branch.
